Preview locally:
  cd starter
  python3 -m http.server 8080
  then open http://localhost:8080

Links are root relative (/blog, /offerings), so opening index.html directly from the folder will not navigate correctly.
Before launch: replace FORM_ENDPOINT in every page (see spec, Decision 2) and add sitemap.xml and robots.txt.
